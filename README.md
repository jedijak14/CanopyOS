# CanopyOS Aurora

CanopyOS Aurora is a desktop-inspired experience that runs in a web browser. Serve the repository as a static site (for example, `python3 -m http.server 8000`) or deploy it to Vercel. Create a local profile to get started; profile data is stored in your browser.

## Highlights

- Open Fern’s compact top-center island from the Dock, menu bar, or with **Option/Alt + Space**. By default Fern opens as a compact wave indicator and starts a one-shot speech-recognition request, which may prompt for microphone permission. Click the waves to stop or restart listening, or use the conversation control to see text and open the full-screen Fern app and Settings. Turn off **Listen when Fern opens** in Fern Settings or System Settings → Fern to avoid the automatic request. Listening stops on close or when the page is hidden. The waves indicate recognition state and speech activity, not measured microphone volume. Browser support and permissions vary; if speech recognition is unavailable or denied, Fern opens its conversation so you can type. Your current conversation stays in place when switching views. Fern shows listening, processing, and response status indicators. You can type or use the microphone where supported; voice recognition may use your browser’s speech provider. Fern Live has been removed.
- **Screen awareness is on by default.** For an online question, Fern includes a bounded text snapshot of the topmost non-Fern CanopyOS app, including up to 4,000 characters of an open note, with its request to the existing external service. Local commands do not send the snapshot, and full-screen Fern does not send text from windows hidden behind it. Turn this off in Fern’s full-screen Settings or System Settings → Fern. Password fields and other input values are excluded, and Fern cannot read host apps, your device screen, or cross-origin embedded sites. This is text context, not visual screenshot or video awareness. Raw context is not stored in the chat history, though Fern’s answer may quote it.
- Drag and drop an image, video, or plain text file onto Fern to prepare it locally. It is sent only when you submit the next question, and can be removed before then. Image/video limits are 40 MB and five minutes; video is sampled as four images without audio. Text files are limited to 100 KB, with the first 12,000 characters sent. Fern’s existing `openai` model is unchanged; media analysis depends on provider support and availability.
- On first use and after a CanopyOS restart, the repository-provided Ventura hello recording plays over the Tahoe wallpaper. Press Enter or the button to continue in the currently displayed greeting’s language. The selected language is saved in the browser and used by the first-profile form, common desktop controls, date/time formatting, speech recognition, and Fern’s online reply language. You can change it in System Settings → Language. Localization is incomplete: some app descriptions, commands, and other text remain English; untranslated labels fall back to English. User content is never automatically translated. The 1920×1080 source is masked at its native greeting resolution without stretching; if H.264 fails, a 1080p VP9 copy of the recording is tried. If both formats fail, or reduced motion is requested, a static source frame is shown instead. Bundled Noto fonts support CJK and complex scripts on systems without those fonts (SIL OFL, see `assets/fonts/NOTICE.txt`). First-run setup lets you choose a language, region, time zone, and local profile. The region seeds the holiday calendar; the time zone affects the menu clock, Clock app and Fern, not the host device clock. Setup descriptions and other interface text remain partly untranslated. New feature releases play a short hello and show a per-profile What’s New; reopen it from the Canopy menu. To announce a future feature, update the release cards and bump `RELEASE.id` in `index.html`.
- The hello recording was supplied separately in the repository; it is third-party media and is not covered by the project’s Unlicense.
- Fern and Clock share multiple timers. Try “set a timer for 2 minutes called tea”, “pause tea timer”, “resume tea timer”, “how much time is left on the tea timer”, or “cancel all timers”. The active timers and countdown update live in Fern and Clock. Timers without a name refer to the most recent applicable timer.
- Choose a city in Weather or Settings → Location, or explicitly grant current-location access. Weather data comes from Open-Meteo. The Weather live wallpaper follows that location and refreshes periodically. Other animated wallpapers are available in Settings → Wallpaper; reduced-motion preferences are respected.
- Desktop label translations are adapted from GNOME catalogs; attribution and license texts are in `locales/`. Coverage remains incomplete, especially outside common controls and the most-used languages. `npm run audit:locales` lists gaps in a small representative set; it is not an exhaustive audit.
- Add and remove national public-holiday calendars from Calendar, including the US and China. Holiday data is provided by [date-holidays](https://github.com/commenthol/date-holidays); dates can change, and local subdivisions and official one-off changes may not be represented. See `vendor/holidays.LICENSE.txt` for third-party licenses.
- Canopy Browser includes tabs that preserve loaded pages while switching, favorites, history, a start page and Wikipedia-backed suggestions/results, with a direct web-search link. Ctrl/Command+L, T, W and R focus the address bar, create or close a tab, and reload while Canopy Browser is active. Sites that prohibit embedding can be opened in the host browser using the persistent button. A web app cannot defeat a site's framing policy, guarantee availability, or inspect or control cross-origin pages.

## Reset CanopyOS

In **System Settings → About**, choose **Erase CanopyOS** and confirm to delete all CanopyOS profiles, settings, and stored app data in this browser, including photos and Cutline projects. Export anything important first, and close other CanopyOS tabs before erasing. It returns to the hello animation and first-time setup. The operation cannot be undone; if deletion is blocked, it reports that some data may already be gone and offers a retry. It does not erase your actual Mac, other websites, downloaded files, or the separate native browser.

## Native macOS browser

[Canopy Browser for macOS](macos-browser/README.md) is a separate AppKit/WebKit application. It opens websites as top-level pages rather than in CanopyOS's iframe and supports tabs, navigation, downloads, and a search/address bar. Build instructions and limitations are in its README. It uses Apple's WebKit engine; compatibility and permissions vary, and it does not share the web app's data. GitHub Actions builds an unsigned, unnotarized app artifact for each browser change; a real Mac is required to run it.

## Package Manager and Cutline

Open **Package Manager** from the Dock to install the bundled Cutline, Focus, and Color Lab apps for the current profile. They are included with CanopyOS; installation does not download executable software. Remove them from the Installed section. Removing an app keeps its local data; deleting the profile removes its saved Cutline project and Color Lab preference (subject to browser storage availability).

Package Manager links to an independent, experimental browser-based 32-bit Windows runner. The user must open the third-party site and choose a file there; CanopyOS does not transfer a file to it. It may not work for many programs, including 64-bit applications, and has not been verified end-to-end. There is no universal way for this web app to run every Windows executable.

Package Manager → **Inspect .exe** reads the headers of a chosen Windows PE32 or PE32+ executable locally and displays its header machine, subsystem, sections, entry point and certificate-directory presence. It reads small header slices rather than uploading or saving the file. It does not verify Authenticode signatures, determine if a file is safe, unpack installers or install or execute Windows programs. Legacy DOS executables and other formats are not supported. Browser file-selection support is required.

Cutline imports browser-decodable MP4, WebM, and QuickTime videos (up to 300 MB and ten minutes per source). Add, reorder, trim, split, duplicate and remove clips; undo and redo edits; add a project-wide title, aspect ratio, color look, and volume. One project per profile, including the original media blobs, is saved in the browser’s IndexedDB. Storage quotas, private browsing, clearing site data, or device failure can remove or prevent saves; export important work. Starting a new project replaces the saved one. **Ask Fern** sends only a generated question with clip count, total duration, and aspect ratio—not your videos—to Fern’s existing service.

Export renders a 720p WebM in real time using browser canvas and MediaRecorder, with audio when the browser supports Web Audio capture. Keep the tab visible during export. Encoding speed, frame smoothness, audio support and source codec support vary by device and browser; an export can fail or drop frames, and some players may not show a duration for browser-recorded WebM files. This is a simple single-track editor, not a replacement for professional editing software.

**Create with AI** is optional and uses `google/veo-3.1-fast` through Pollinations for a six-second clip. You supply a Pollinations API key each time; it is sent in the Authorization header and is not saved by Cutline. The prompt is sent to Pollinations. Requests consume the key’s credits and depend on account permissions, model availability, provider CORS support and service limits; canceled requests may still be billed. Square projects request a landscape generated clip. There is no promise of free or unlimited generation, and the real provider integration has not been verified with a paid key.

## Android Fern assistant

The `android/` project packages this same CanopyOS app and exposes Fern as an Android voice-interaction assistant. After installation, use Fern's Android assistant settings button (or Android's Default apps → Digital assistant app screen) to select it. Android opens Fern from its assistant gesture; always-on wake-word detection is intentionally not enabled. Fern's spoken replies use the app's downloadable Kokoro neural voice offline after first setup, not the phone's installed TTS voice. Incoming speech uses the Android speech-recognition provider, and open-ended answers still require the existing online model service. Build, voice-model size, and third-party license details are in `android/README.md`.

## Web platform limits

Timers are stored per local profile and continue counting down when the apps are closed or the page is away. Alerts appear when CanopyOS is open or reopened; a closed browser cannot deliver a notification at the deadline. Paused timers remain paused.

This is a web app, not a native operating system or a standalone Chromium distribution. It uses the engine of the browser running it and cannot override a site's frame restrictions. Some pages, including many search and sign-in pages, therefore must open in a separate browser tab. Battery, microphone, and geolocation APIs depend on browser support, secure context, and permissions. Open-ended Fern responses and weather require external services and network access; they can be unavailable. Fern’s normal online requests already include conversation text and basic workspace metadata; when enabled, the current CanopyOS app’s text and the open note are included in online questions. Restart affects this web app, not the host computer. Location is requested only when you choose to use it, and coordinates are saved in your local profile for weather.

## Workspace features

- Every app can enter CanopyOS full-screen with its green window control or **Ctrl + Shift + F**; use the same control or shortcut to restore it. This fills the CanopyOS workspace, not the browser's native full-screen mode. The Window menu also offers left/right tiling (**Ctrl + Alt + Arrow**).
- Open Launchpad from the menu bar, Canopy menu, or **Ctrl + Shift + A**. Spotlight also searches locally stored notes. **Ctrl/Command + M** minimizes, **Ctrl/Command + W** closes the active window, and **Ctrl + Shift + N** creates a note (browser/OS shortcuts may take precedence).
- Reminders supports locally saved tasks, editing, due dates, optional times, completion and filters. Timed reminders notify once while CanopyOS is open (or when the tab resumes); they cannot alert while the browser is closed. Activity Monitor shows CanopyOS windows, browser connectivity and estimated browser storage, not system-wide processes or CPU usage.
- Click the menu-bar clock for notification history. Focus in Control Center suppresses CanopyOS notification pop-ups during the current session while retaining them in history. Wi-Fi and Bluetooth are managed by the host device, not this web app.

- The translucent Dock supports magnification, size, and optional auto-hide in Settings → Dock. Mission Control (**Ctrl + Shift + M**) lists open and minimized windows; **Ctrl + Shift + D** shows the desktop or restores its windows. The menu bar clock can use 24-hour time.
- Notes can be duplicated and exported as plain text. Calendar events can be edited and exported as an iCalendar file; exported events exclude the separately maintained holiday calendars.

Run `npm install` and `npm test` for the automated workspace smoke tests.
